# 🛠️ BharatKart Admin Panel

**BharatKart Admin Panel** is the administration dashboard for the BharatKart e-commerce web application.

It provides an interface for administrators to manage products, view customer orders, and manage the e-commerce application's Firebase-powered data.

---

## 🛒 About BharatKart

BharatKart is a modern e-commerce web application built using HTML, CSS, JavaScript, and Firebase.

This repository contains the **Admin Panel** used to manage the BharatKart storefront.

---

## ✨ Features

- 🔐 Admin authentication
- 📊 Admin dashboard
- 📦 Product management
- ➕ Add products
- ✏️ Edit products
- 🗑️ Delete products
- 🛒 View customer orders
- 📋 View order details
- 🔄 Update order status
- 🔥 Firebase Authentication
- ☁️ Firebase Firestore integration
- 📱 Responsive admin interface
